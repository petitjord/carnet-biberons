        Partager le carnet

        Avec un code famille, vous voyez tous les deux les mêmes biberons depuis vos deux téléphones, même si l'un d'eux est hors connexion un moment.

        Donne ce code à l'autre parent. Il le colle dans « Partager » sur son téléphone. Toute personne qui connaît ce code peut lire et modifier le carnet : ne le publie nulle part.

        Les biberons sont enregistrés chez Google (Firebase) sous ce code, et gardés aussi sur chaque téléphone.
